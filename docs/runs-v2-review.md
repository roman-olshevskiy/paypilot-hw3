## Важливий хибний PASS RET-H01

У v2 модель назвала spread 0.5%, але явно відмовилася підтверджувати allowance. Вона написала:
«The allowance could be EUR 5,000 or another figure beginning with 5, so I won't guess it.»
Обидва пошуки принесли лише tariffs.md#b3, який закінчується EUR 5.
Наш L3 regex побачив 0.5% та 5,000 і зарахував PASS, хоча allowance наведений лише як гіпотеза.
Це хибне позитивне спрацювання тесту. 7/10 runner не дорівнює семи коректним відповідям; ручний розбір дає 6/10 із підтвердженими потрібними числами в самій відповіді.
Це ручне уточнення не змінює raw report і не є context recall.
Тест RET-H01 надалі потребує перевірки підтвердженого твердження про allowance або структурованої відповіді з перевіркою статусу достовірності.
Не виправляти завершений verdict чи прогноз заднім числом.

RET-H07 знову назвав правильні 1.2% із quick reference у prompt D05; fees-detail.md#b2 потрібного числа не містить.
Його PASS відповіді не доводить успішний retrieval. H02/H04 також читають числа з таблиці з обрізаним заголовком.
